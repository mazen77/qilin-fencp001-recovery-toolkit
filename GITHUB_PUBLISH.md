# Publish on GitHub / النشر على GitHub

## English

This package is the **public-safe** edition. It contains no victim data, incident hashes, company/product identifiers, victim-specific extensions, ransom contacts, or live malware.

Create an empty repository, for example `qilin-fencp001-recovery`, then run:

```bash
git init
git add .
git commit -m "Initial public release: Qilin FENCP001 Recovery Toolkit 1.1.0"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/qilin-fencp001-recovery.git
git push -u origin main
```
