# Security and Evidence Handling

- Do not execute ransomware samples or unknown `.exe` files while using this project.
- Work on copies; preserve hashes of originals.
- The toolkit is read-only with respect to source files and writes separate outputs.
- Do not publish victim databases, live ransomware binaries, credentials, private keys, or personal data in issues or pull requests.
- Treat `stable-four-way` output as heuristic evidence only.
- A sparse output is not a complete decrypt unless the stream map covers every encrypted byte.
